## A. 研究定位

- **問題價值**：要先確認我們回答的問題，是不是銀行有興趣、對銀行有價值的問題。明天的會議要跟銀行確認他們要的東西。
- **研究目的**：我們是在讓 AI 複製處置效應，不是在寫學術論文。銀行只需要一個可以複製處置效應的東西。
- **因果推論與內生性**：簡章有識別效果的評分，但教授認為我們不是做因果推論，研究不是要因果，所以不用處理內生性問題。
- **與業界溝通**：不要講 regression，把 PLR、PGR 寫好就好，因為業界的人看不懂 regression。

## B. 核心問題：只靠記憶不夠

- 有記憶未必能呈現處置效應，甚至可能出現相反的處置效應。
- 如果目標是重現處置效應，只讓記憶更長是不夠的。目前已證明光有記憶不夠。
- 銀行可能對「如何下 prompt 才能複製處置效應」更有興趣。教授建議從記憶以外的面向下 prompt，並處理「哪種方法下 prompt 可以處理」。
- **記憶架構**：教授強調不用更動。架構可以保留，只是針對 prompt 搭配使用。

## C. Prompt 設計方向（persona）

### 1. 不要 delabel

- 我們原本打算 delabel，但教授認為不是限制，因為我們的目的是讓 LLM 重現處置效應。把它當作什麼都不知道，對實踐來說似乎不是很有效的方法。
- 這似乎是介入模型，會讓模型越來越不重現處置效應。

### 2. 改用 persona

- 這是更直接的方法，可以用不同的設定，也可以參考過去的文獻。
- 處置效應不只記憶可以誘發，還有偏好、效用函數等，例如 loss aversion。
- 目前的 prompt 不夠：現在只有年齡、職業等，但重點可能在心理狀態。不同 prompt 的結果可能不同。
- 關鍵是回到財務上的重點：怎麼下 prompt 可以重現處置效應，也就是會觸發處置效應。

### 3. 不要亂槍打鳥，回到學術文獻

- 教授認為有些設定要回到學術文獻上，例如後悔：可以告訴 AI「你是比較後悔趨避的投資人」、實現效用等。
- 我們可以把學術上不同的設定問給 AI，讓它呈現。我們要 leverage 學術上的發現。
- 學術上也發現，experienced、高頻交易的交易人，處置效應較小。

### 4. persona 分類（每類用不同的 prompt）

- 心理類
- 人口統計類
- 投資經驗類：財務教育、相關科系、專業投資知識等

## D. 參數與設定

- **paper gain (G) 的參考基準**
    - 用平均成本。打開 app 就有，一般投資人就是用這個來看。
    - 教授建議不管其他怎麼設定，但要讓所有人都知道過去的平均成本。
- **穩健性測試**：例如「投資人只記得第一次買入價格」，這就是好的設定，不用管內生性問題。

## E. 資料與時間範圍

- 與銀行政策有連結。我們的資料只有 1999 年以後，但我們參考的論文（Barber）用的資料是 1995–1999 年。
- 重點在於我們的 prompt 能不能穩定地重現處置效應。
- 不要陷於論文所用的時間資料，因為那個 regime 已經過去了。重點是不同的市場環境下都可以有處置效應。
- Barber 的論文只反映那個時間。教授認為「不是像就是好」，也就是結果跟論文相像不代表就好，重點是可重現性。

- Prompt 很難控制。
- 直接用 benchmark 說明「有處置效應」，看模型能不能扮演好有處置效應的角色。

## H. 教授貼出的研究架構（會後文字，非會中口述）

### 1. 建議的研究問題

1. 哪些 prompt 設定可以使 LLM agent 重現人類投資人的處分效應？
2. 不同 prompt 設定所產生的處分效應是否具有穩定性？
3. 累積記憶是否有助於提升處分效應的重現程度與穩定性？

### 2. Prompt 設計面向

| 實驗變數 | 不同設定 |
| --- | --- |
| 行為偏誤 | 不指定、直接指定具有處分效應 |
| 心理特徵 | 展望理論、心理帳戶、後悔趨避、實現效用 |
| 投資人特徵 | 金融知識、投資經驗、專業程度 |
| 累積記憶 | 無記憶、歷史交易紀錄、歷史交易紀錄加反思 |
| 市場認知 | 是否告知股票報酬率的生成過程 |

### 3. 研究階段

| 階段 | 研究內容 |
| --- | --- |
| 第一階段 | 比較不同 prompt 設定能否產生處分效應。 |
| 第二階段 | 針對能夠產生處分效應的 prompt，檢驗加入累積記憶是否影響其程度與穩定性。 |
| 第三階段 | 改變價格路徑、波動度、交易期間及模型版本，檢驗結果是否穩健。 |

### 4. 評估指標

| 評估指標 | 意義 |
| --- | --- |
| 重現能力（Reproducibility） | 能否產生正向處分效應？ |
| 模擬準確性（Accuracy） | 處分效應的程度是否接近真實投資人？ |
| 穩定性（Stability） | 改變市場情境或重複執行後，是否仍能維持類似的行為特徵？ |

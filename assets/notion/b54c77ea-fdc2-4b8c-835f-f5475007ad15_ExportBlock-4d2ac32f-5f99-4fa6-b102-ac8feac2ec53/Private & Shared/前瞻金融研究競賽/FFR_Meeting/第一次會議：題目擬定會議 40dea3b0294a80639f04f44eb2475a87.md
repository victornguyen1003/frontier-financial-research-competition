### 2. 主題發表

**共同背景**：三人都選了「生成式 AI 行為 / 金融」題（簡章要求用 AI agent 搭配累積記憶模擬投資人，檢驗行為財務理論，如處分效應、損失趨避）。核心現象是**處分效應（disposition effect）**：太早賣出賺錢的股票、太久持有賠錢的股票；問題是 AI agent 通常太理性，不會自然出現這類行為。

#### Victor：用記憶架構控制 agent 行為

- 參考 Generative Agents 論文（25 個 agent 的模擬）：observation → reflection → planning 的記憶架構。
- 設計：資料固定，只改變記憶設定（無記憶 / 僅 observation / observation + reflection），觀察處分效應是否改變；有餘力再延伸到損失趨避、羊群效應，或加入「市場崩盤 / 繁榮」的歷史記憶看 agent 會變保守或激進。
- 已用規則式（deterministic、未接任何模型）做出初步模擬原型；預計用 OpenAI API（手上約 150 USD 額度）。
- 規劃：初賽 12 月，時程只有約 6 週。

#### Jim：拆解文獻分歧來源

- 動機：最新文獻中，有的研究發現 LLM 有明顯處分效應，有的沒有，想找出分歧來自**標籤（金融詞彙）**、**記憶**還是其他因素。
- 實驗 A（標籤）：盲標籤（去掉金融詞彙）vs. 正常標籤，只給起點與終點、不給中間路徑。
- 實驗 B（記憶）：固定起訖點、隨機生成不同歷史路徑當作記憶，約需 8,000 次 API 呼叫。
- 迴歸：logit，主檢定為「帳面損益 G（dummy）× blind」的交互作用，結果可直接轉成機率；只設兩個主檢定以避免偽陽性，其餘放描述性分析。
- 政策關聯：提供銀行用 LLM 模擬客群時的稽核方法（提示敏感度測試、記憶內容測試、規範答案基準）。
- 時程：11/20 前先跑 pilot，測 API 並評估檢定力，不足再加跑次數。
- 風險：後續仍仰賴教授是否提供原始資料，否則只能用論文資料做描述性分析。

#### Justin：複製、記憶框架與 agent 類型

- 三個切入點：(1) 複製論文，看有記憶的 agent 是否跟真人一樣有處分效應；(2) 比較記憶框架（in-context memory、RAG、甚至 fine-tune）；(3) 用記憶設定出不同投資人類型的 agent，增加報告亮點。
- 模型：解釋變數用不同的 memory setting，被解釋變數用 PGR − PLR（已實現獲利比例 − 已實現損失比例）；論文中的公司層級資料（散戶、法人的 PGR / PLR）可與不同 memory setting 對照，是最快的比較基準。
- 資料污染疑慮：模型可能已看過該論文，故用 bootstrap sampling 從真實期間任意抽樣組合，避免模型事先知道後續走勢。
- 結果不顯著時：仍可用描述統計說明不同記憶設定下 LLM 的差異（簡章要求誠實說明結果）。
- 其他兩題的可行性：
    - **ESG / 氣候變遷**：系上教授認為應用面主要是碳費，但台灣 2025 年才試徵、2026 年才開徵，資料不足，不可行。
    - **普惠金融**：中小企業聯徵信用資料很難取得，不可行。

### 4. 會議結論

- **題目**：三人收斂到「AI agent × 行為財務」，以記憶設定對處分效應的影響為主軸。
- **迴歸共識**：以 agent 在每一期是否賣出（0/1）為被解釋變數，用 logit 估計；解釋變數為記憶設定（dummy）、帳面損益 G（paper gain）、**Memory × G 交互項（主檢定）**、drawdown 與控制變數；資料為 agent × 期數的 panel，標準誤依 agent cluster。Jim 同意採用 Victor 的設定，原本的 prompt 實驗不再採用。
- 記憶細節（層數、反思頻率等）與實驗規模留待下次會議。

### 5. 白板討論整理

> 由白板照片整理，部分手寫字跡難辨識，請對照原圖確認。
> 

**研究問題與兩階段邏輯（紅色）**

- 第一問：LLM agents 是否表現出處分效應（DE）？白板寫「LLM agents are not rational」，假設答案為 No。
- 第二問：Why？→ 檢驗 Memory 是否是原因。

**資料結構**

- 1 個 agent = 1 條價格路徑，每天輸出 sold ∈ {0,1}（序列 1,0,1,… 共 T 天），視為 sold ~ Bernoulli(p)。
- 100 條路徑 → 100 個 agent → 100 筆觀測 → 迴歸估 β。路徑來自資料 bootstrap 或 Monte Carlo 模擬。

**迴歸式**

$$
P(Sold_{it}=1)=\Lambda\left(\alpha+\beta_1\,Memory_i+\beta_2\,G_{it}+\beta_3\,(Memory_i\times G_{it})+\beta_4\,dd_{it}+\gamma'X_{it}\right)
$$

其中 Λ 為 logistic 函數；Sold 為 0/1，故用 logit。

- **Memory_i**：三種記憶設定（no memory / observation / observation + reflection），以兩個 dummy 表示，baseline 為 no memory。
- **G_it**：帳面損益 dummy（G=1 為帳面獲利）。**β₂ > 0 即代表出現處分效應**（第一問）。
- **Memory_i × G_it**：**主檢定**。檢驗不同記憶設定下處分效應是否不同（第二問）；若只放 Memory_i，只能看記憶是否改變整體賣出機率，無法回答記憶是否改變處分效應。
- **dd_it**：drawdown；與 G 同樣來自價格路徑，可能共線，需檢查，必要時調整。
- **X_it**：控制變數；temperature、模型固定不變。
- 標準誤依 agent（路徑）做 cluster，因同一 agent 有多期觀測。
- 白板原式：Sold_t ~ α + β·dd_t + γ·G_t + … + control，再加上 **β·memory**（標註「prevent bias」）。
- 資料表欄位：Sold_{i,t}、Memory_i（記憶設定 1, 2, …）、G_{i,t}（帳面損益 dummy，右側用起始 100 → 110 與 90 的範例說明 G=1 / G=0）、dd_{i,t}（drawdown）。

**記憶實驗設計**

- 兩種「記憶」定義並列：
    - ① prompt 架構：no memory、observation、observation + reflection，各 ×100 條路徑，各得 100 筆 sold，再迴歸。
    - ② 1 memory = 1 path（不同路徑 / drawdown 代表不同記憶）。

**藍色開放問題 (B)**：Quantify the value of the prompt—例如 trading hard → $100、trading slow → $50，如何讓不同 prompt 的效果可比較。

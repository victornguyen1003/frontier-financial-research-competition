### 本次會議記錄

#### 1. 原型彙報(Victor)

- 價格路徑以 Monte Carlo 生成:假設波動度 10%、均值 0(random walk、無趨勢),參數未由真實資料估計
- 設定:3 種記憶架構(no memory / observation log / reflection,於第 5、10 期後歸納 3 點 lesson)× 數個 persona,共 15 期、5 檔股票、100 條路徑;各 agent 獨立訓練、不互相交易(對應教授的想法為 study two)
- no memory 設定下,agent 看不到自己過去的買賣與損益,但可看到公開的歷史價格
- 結果:處分效應(disposition effect)係數在多數群組為負且顯著,僅 retiree 不顯著 → 方向與預期相反;persona 數量太少(僅 3 個)且年齡等設定(如 27 歲)缺乏資料依據,需改用真實統計資料

#### 2. 結果為何相反與模型污染

- 可能原因:LLM 猜到實驗意圖(prompt 暴露在測處分效應)而反向操作;或訓練資料中已含處分效應相關論文/知識
- Min-K% Prob 需要模型回傳 token 機率,API 無法使用,須改用開源模型,暫不採用
- 價格污染可由 Monte Carlo 解決;論文污染目前無解,列為要問教授的問題
- 可嘗試的做法:system prompt 中不出現金融/股票字眼(de-label)、做 robustness test、重複跑多次確認方向是否穩定、先跑 pilot 檢查統計檢定力(power test)
- 結論:不論結果方向都要有可寫的內容;若為負值或接近零,可解讀為「記憶設定是影響模擬市場結果的重要參數」,並需思考如何連結政策

#### 3. 模型適配性(與 Barber et al. (2007) 比較)

- 目前輸出為 level,論文為比率 → 改以 odds ratio 比較,並報告 marginal effect(令 G=1 與 G=0 的預測機率差),因交互項係數不能直接解讀
- 試算結果:本模型 odds ratio 約 2.74,論文為 2.629,數值接近,方法可行
- period 需與論文對齊(一個 trading day)
- 標準誤:採 cluster by path(研究對象是同一條價格路徑在不同記憶設定下如何被交易);cluster by agent 為對照,兩種都可測試

#### 4. 「記憶」的定義與 prompt 量化

- 三種記憶設定:0 = 無記憶(baseline)、1 = 含歷史回測資料、2 = 含 reflection
- 疑慮:不同組的 system prompt 長度不同,可能產生安慰劑效應(placebo),需納入考量
- prompt 量化:不以價格報酬(martingale 市場下平均為 0,無意義),改以 token 數量/budget 上限衡量;此做法仍待討論
- RAG 與 fine-tuning 與本研究關聯低,不做

#### 5. 路徑生成

- 採 Monte Carlo 而非 bootstrap:bootstrap 假設分布不隨時間改變,不適合;martingale 只能指定起點,不能指定終點
- 若要與論文比較,可用 1994–1999 的波動度估計參數,但 TEJ 資料只到 1999 年以後 → 詢問教授是否有資料

#### 6. G(paper gain)的基準:cost basis

- 方案一:固定 cost basis(如 100 元)→ 識別乾淨、避免內生性,但買回後成本改變時失真
- 方案二:依論文使用變動的平均成本 → 可比較性佳,但 G 會因買賣而有內生性
- 評分標準中「與論文行為一致」佔 30%,多數傾向以符合論文為優先;論文本身亦有內生性問題,可問教授;本週先用論文的變動成本跑 pilot
- 另需決定:賣光後 agent 沒錢/沒股票怎麼辦(是否退出)

#### 7. 迴歸設定

- 以 prototype 為基礎(panel:i = agent、j = 股票、t = 時間),再加入 Memory × G 交互項與控制變數(dd、period、persona、seed)
- return 與 dd 高度相關,是否放入待測試(兩者同時放入看係數是否仍顯著)
- 需決定報告項目:odds ratio、marginal effect,並對照論文的 PGR / PLR
